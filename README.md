# StudySpark India

Prompt: > "Build a premium EdTech platform for Indian students (Grades 9-12).

Architecture:

Landing Page: Modern hero section with a search bar: 'Search for PYQs, Notes, or Courses.'

Navigation: Sidebar or Top-nav with categories: Classes (9, 10, 11, 12), Subjects, and Resource Types (Notes, PYQs, Question Bank).

Resource Grid: Use a 'Card' layout to display resources. Each card should show the Class, Subject, and a 'Download PDF' or 'View' button.

Filters: A sidebar filter system for Board (CBSE/ICSE), Subject, and Year for PYQs.

UI/UX Style: > Use a 'Bento Box' grid layout. The aesthetic should be 'Glassmorphic'—very smooth, rounded corners (rounded-2xl), subtle shadows, and high-quality typography (Inter or Geist font). Use a professional color palette like Deep Indigo and Electric Blue.

Tech: Set up a Supabase table structure for 'Resources' including fields for title, class_level, subject, and file_url."
